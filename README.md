# trader_sentiment_analysis_DA
📊 Sentiment-based trading analysis using Fear &amp; Greed Index to evaluate trader behavior, profitability, and strategy insights with data visualization and Streamlit dashboard.

# 📊 Trader Sentiment Analysis

## 📌 Objective

Analyze how market sentiment (Fear/Greed) impacts trading behavior and performance.

---

## ⚙️ Setup

```bash
pip install pandas matplotlib seaborn streamlit
```

---

## ▶️ Run Notebook

Open:

```bash
notebook/analysis.ipynb
```

---

## 🌐 Run Dashboard

```bash
streamlit run app.py
```

---

## 📊 Key Insights

* Trades during **Extreme Greed** show highest profit
* **Fear conditions** still provide stable returns
* Majority trades happen in **Greed & Extreme Greed**
* Long positions dominate across all sentiments

---

## 💡 Strategy Recommendations

* Focus trading during **Extreme Greed**
* Avoid overtrading in **Neutral sentiment**
* Use **Fear periods** for safer entries
* Balance long/short to reduce risk
